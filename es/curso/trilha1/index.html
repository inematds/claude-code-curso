📦 Instalación y primer comando

Del npm install al primer prompt funcional. Todo lo que necesitas para empezar a usar Claude Code hoy.

Qué es:

Las tres formas de instalar Claude Code: npm, Homebrew y winget.

Por qué aprender:

Sin una instalación correcta, nada más funciona.

Conceptos clave:

Node.js 18+; npm global install; autenticación con API key.

Qué es:

Ejecutar el comando claude por primera vez y entender lo que aparece.

Por qué aprender:

El primer paso real. Sin él, lo demás es teoría.

Conceptos clave:

Interfaz interactiva; prompt de Claude; respuesta en línea.

Qué es:

claude (interactivo) vs claude -p "pregunta" (one-shot, sin sesión).

Por qué aprender:

Saber cuándo usar cada modo ahorra tiempo y contexto.

Conceptos clave:

Modo interactivo = conversación; flag -p = one-shot; pipes con -p.

Qué es:

Los flags que usarás todos los días: --help, --version, -p, --model, --verbose.

Por qué aprender:

Conocer las flags evita perderse en Google.

Conceptos clave:

--help como referencia rápida; flags más usadas.

Qué es:

Cómo actualizar Claude Code y verificar la versión instalada.

Por qué aprender:

Las nuevas versiones incluyen funciones y correcciones importantes.

Conceptos clave:

npm update -g; changelog; cambios incompatibles.

Qué es:

Los errores más comunes durante la instalación y cómo resolver cada uno.

Por qué aprender:

Saber resolver errores evita que te bloquees al principio.

Conceptos clave:

EACCES permission; Node version mismatch; auth errors.

⌨️ Navegando el CLI como un pro

Atajos de teclado, slash commands, sesiones y pipes que multiplican tu velocidad.

Qué es:

Los atajos de teclado de Claude Code: Escape, Tab, Ctrl+C y más.

Por qué aprender:

Los atajos ahorran clics y mantienen el foco en la terminal.

Conceptos clave:

Escape para cancelar; Tab para aceptar; Ctrl+C para interrumpir.

Qué es:

Comandos con barra dentro de la sesión interactiva de Claude Code.

Por qué aprender:

Son el panel de control dentro de la conversación.

Conceptos clave:

/help; /clear; /model; /memory; /resume; /compact.

Qué es:

Qué modelo se ejecuta detrás de Claude Code y cómo funciona el contexto.

Por qué aprender:

Entender el modelo ayuda a calibrar las expectativas y los costos.

Conceptos clave:

Opus/Sonnet; ventana de contexto; presupuesto de tokens.

Qué es:

Las sesiones persisten entre ejecuciones. /resume retoma la conversación anterior.

Por qué aprender:

No perder el contexto de trabajo al cerrar la terminal.

Conceptos clave:

Session ID; /resume; flag --resume; selector de sesiones.

Qué es:

Claude Code lee imágenes del filesystem y analiza capturas de pantalla.

Por qué aprender:

Debug visual, reproducir diseños, leer diagramas.

Conceptos clave:

Arrastrar y soltar; pegar una captura de pantalla; referencia mediante path.

Qué es:

Usar claude -p con pipes de Unix: | jq, | grep, > archivo.

Por qué aprender:

La integración nativa con el ecosistema Unix multiplica el poder.

Conceptos clave:

Stdout; --output-format json; piping con jq; scripts wrapper.

🧠 CLAUDE.md — el cerebro del proyecto

El archivo que convierte a Claude Code de genérico en especialista en tu proyecto.

Qué es:

Un archivo Markdown que Claude Code lee automáticamente en cada sesión.

Por qué aprender:

Es la única forma de darle al agente contexto persistente sobre tu proyecto.

Conceptos clave:

System prompt; instrucciones persistentes; contexto del proyecto.

Qué es:

~/.claude/CLAUDE.md (global) > ./CLAUDE.md (proyecto) > subdir/CLAUDE.md (carpeta).

Por qué aprender:

Cada nivel resuelve un problema de alcance diferente.

Conceptos clave:

Cascada de instrucciones; herencia; override por nivel.

Qué es:

Cómo escribir CLAUDE.md para que el modelo realmente lo siga.

Por qué aprender:

Un CLAUDE.md mal redactado se ignora; uno bueno lo cambia todo.

Conceptos clave:

Encabezados claros; listas; ejemplos; tono imperativo.

Qué es:

Qué tipos de instrucciones realmente cambian el comportamiento del agente.

Por qué aprender:

Menos instrucciones acertadas > muchas instrucciones vagas.

Conceptos clave:

Stack; convenciones; prohibiciones; patrones del proyecto.

Qué es:

Ejemplos comentados de CLAUDE.md de proyectos reales.

Por qué aprender:

Ver ejemplos reales acorta la curva de aprendizaje.

Conceptos clave:

Patrones comunes; antipatrones; tamaño ideal.

Qué es:

CLAUDE.md debe evolucionar junto con el proyecto e ir en git.

Por qué aprender:

Un CLAUDE.md desactualizado es peor que no tener ninguno.

Conceptos clave:

Hacer commit en el repo; revisar mensualmente; /memory como complemento.

⚙️ Configuración avanzada

settings.json, .claudeignore, permisos y variables de entorno para ajustar Claude Code.

Qué es:

El archivo JSON que controla el comportamiento global y por proyecto.

Por qué aprender:

Sin settings.json, te quedas con los defaults genéricos.

Conceptos clave:

~/.claude/settings.json; .claude/settings.json; combinación de configuraciones.

Qué es:

Archivo que indica a Claude Code qué archivos/carpetas debe ignorar.

Por qué aprender:

Protege secretos, reduce el contexto innecesario y acelera al agente.

Conceptos clave:

Sintaxis glob; .env; node_modules; build artifacts.

Qué es:

Definir qué herramientas puede usar Claude Code sin pedir permiso.

Por qué aprender:

Equilibrar la seguridad con la productividad.

Conceptos clave:

allowedTools; deniedTools; solicitudes de permiso; niveles de confianza.

Qué es:

Variables de entorno que Claude Code reconoce: ANTHROPIC_API_KEY, CLAUDE_MODEL, etc.

Por qué aprender:

Configuración por entorno sin tocar archivos.

Conceptos clave:

ANTHROPIC_API_KEY; CLAUDE_MODEL; .env local.

Qué es:

Diferentes configuraciones para distintos proyectos/contextos.

Por qué aprender:

Un proyecto personal y uno corporativo tienen necesidades diferentes.

Conceptos clave:

Settings local vs global; herencia de configuraciones.

Qué es:

Cómo usar --model, /model y proveedores alternativos (Bedrock, Vertex).

Por qué aprender:

Flexibilidad para usar el modelo adecuado en cada tarea.

Conceptos clave:

--model flag; CLAUDE_MODEL; Bedrock; Vertex AI.

💾 Memoria y contexto persistente

Cómo funciona la memoria, qué es context window, compaction y estrategias para no perder el contexto.

Qué es:

Claude Code no tiene memoria mágica. Todo vive en la ventana de contexto de la sesión.

Por qué aprender:

Entender el modelo mental evita frustraciones con «se olvidó».

Conceptos clave:

Context window = memoria de trabajo; CLAUDE.md = memoria persistente.

Qué es:

/memory guarda notas persistentes que Claude Code lee en cada sesión futura.

Por qué aprender:

Es la forma rápida de enseñar preferencias sin editar CLAUDE.md.

Conceptos clave:

/memory; CLAUDE.md generado; ~/.claude/CLAUDE.md.

Qué es:

La ventana de contexto tiene un límite fijo (200k tokens). Todo compite por espacio.

Por qué aprender:

Cuando el contexto se llena, baja la calidad de las respuestas.

Conceptos clave:

Tokens; límite de contexto; degradación gradual.

Qué es:

Claude Code resume automáticamente la conversación cuando se llena el contexto.

Por qué aprender:

Compaction hace perder detalles. Saber cuándo ocurrirá te ayuda a prepararte.

Conceptos clave:

/compact manual; auto-compaction; qué se pierde.

Qué es:

Estrategias para transferir contexto de una sesión a otra.

Por qué aprender:

Las sesiones largas se degradan. Saber cómo dividirlas mantiene la calidad alta.

Conceptos clave:

/resume; resumen manual; CLAUDE.md como handoff.

Qué es:

Técnicas para guardar el estado del trabajo antes de que se llene el contexto.

Por qué aprender:

Los puntos de control evitan perder el progreso en tareas largas.

Conceptos clave:

Commits de Git como checkpoint; notas en CLAUDE.md; archivos TODO.

🛠️ Tu workflow personal

Aliases, scripts wrapper, tmux, VS Code y la configuración definitiva para usar Claude Code todos los días.

Qué es:

Aliases de shell que acortan los comandos frecuentes de Claude Code.

Por qué aprender:

Cada segundo ahorrado se multiplica por cientos de usos.

Conceptos clave:

alias cc='claude'; alias ccr='claude --resume'; .bashrc/.zshrc.

Qué es:

Scripts de shell que combinan claude -p con otras herramientas.

Por qué aprender:

Los scripts wrapper automatizan tareas repetitivas con IA.

Conceptos clave:

Scripts wrapper; entrada mediante pipe; análisis de la salida.

Qué es:

Usar Claude Code dentro del terminal de VS Code y con la extensión oficial.

Por qué aprender:

VS Code es el editor más usado. Una buena integración maximiza la productividad.

Conceptos clave:

Terminal integrado; extensión Claude Code; lado a lado.

Qué es:

Usar tmux o screen para ejecutar Claude Code en sesiones persistentes.

Por qué aprender:

Las sesiones sobreviven a las desconexiones y permiten varios agentes.

Conceptos clave:

tmux new-session; paneles lado a lado; detach/attach.

Qué es:

Mantener las configuraciones de Claude Code en archivos dotfiles versionados.

Por qué aprender:

Setup reproducible en cualquier máquina nueva.

Conceptos clave:

Repositorio de dotfiles; symlinks; script de bootstrap.

Qué es:

La configuración completa que combina todo: aliases + tmux + VS Code + dotfiles.

Por qué aprender:

Una referencia concreta de cómo encaja todo.

Conceptos clave:

Flujo integrado; ritmo diario; evolución incremental.

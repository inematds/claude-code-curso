4.1~40 min

Subagents — Concepts

What subagents are, the Task tool, and when to use parallelism.

What is:

Subagents are Claude Code instances launched by the main agent to perform isolated tasks.

Why learn:

Allows you to scale work without cluttering the main agent's context.

Key concepts:

Parent-child; context isolation; delegation.

What is:

Claude Code's internal tool for creating subagents with their own prompt and context.

Why learn:

It's the primary interface for orchestrating parallel work.

Key concepts:

Task(prompt); result returned; limited scope.

What is:

Subagents can have different permission levels: read, write, or background.

Why learn:

Choosing the right type avoids conflicts and reduces risk.

Key concepts:

Principle of least privilege; specialized agents.

What is:

The parent sends instructions and context; the child returns a text result when it finishes.

Why learn:

Understanding the workflow prevents information loss between agents.

Key concepts:

Input prompt; structured output; no shared state.

What is:

Git worktrees let each subagent work on files without conflicting with others.

Why learn:

Without isolation, parallel agents step on each other’s toes.

Key concepts:

git worktree; temporary branch; merge later.

What is:

Subagents have context overhead and cost. Not every task warrants parallelism.

Why learn:

Avoid wasting tokens on simple tasks.

Key concepts:

Overhead vs. gains; independent tasks; minimal complexity.

What is:

What is:

Multi-Agent Patterns

Architectural patterns: fan-out/in, pipelines, specialists, and cost control.

What is:

Distribute work to N agents and bring the results together in one place.

What is:

Chain agents so that one agent’s output feeds the next.

What is:

One agent explores the codebase, another plans, and another executes. Separation of concerns.

What is:

Agents with specific prompts for tests, docs, lint, or security.

What is:

Retry, fallback, and circuit-breaker patterns adapted for AI agents.

What is:

Limit tokens per subagent, use smaller models for simple tasks, measure ROI.

Claude understands the context on both sides and resolves conflicts semantically.
